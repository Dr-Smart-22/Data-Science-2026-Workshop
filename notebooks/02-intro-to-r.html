Part 2 — Read the data and look at it

Here we read in the instructional dataset files using read_csv(). This function comes from the readr package (part of the tidyverse) and turns a CSV file into a data frame — R’s version of a spreadsheet with rows and columns.

# Read the sample IDs file — this tells us which samples belong to which participant
samples <- read_csv(here("data", "instructional_dataset", "00_sample_ids_UKZN_workshop_2023.csv"))

# Read participant metadata — age, smoking status, education, etc.
metadata <- read_csv(here("data", "instructional_dataset", "01_participant_metadata_UKZN_workshop_2023.csv"))

# Read clinical measurements — Nugent score, CRP, pH
clinical <- read_csv(here("data", "instructional_dataset", "02_visit_clinical_measurements_UKZN_workshop_2023.csv"))
